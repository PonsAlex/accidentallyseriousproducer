# Examples only

This directory is part of the public ASP repository and may be published by
Cloudflare Pages. It is not an Odysseus queue.

Only anonymized contract examples may be committed here. Real promotion
candidates, sender data, email subjects, extracted links and review material
must remain in private Odysseus storage, such as:

```text
/app/data/asp_affiliate_candidates/
G:\ODYSSEUS\data\runtime\asp_affiliate_candidates\
```

After human approval, only sanitized public records may be proposed for:

```text
data/products.json
data/affiliate-links.json
data/promotions.json
```
